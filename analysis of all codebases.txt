I. General Observations and Key Insights

Inconsistent Problem Detection: Most codebases struggle with accurately detecting the full range of problems. They often either over-detect (e.g., identifying salt and pepper noise where there is none) or miss crucial issues (e.g., failing to detect blur or foreign objects). This highlights the need for more specific and reliable detection methods.

Sensitivity to Parameter Choices: Many image processing techniques, like adaptive thresholding, Gaussian blur, and even CLAHE, are highly sensitive to the parameters used. A single set of "magic numbers" won't work for all images. We need to either make these parameters adaptive or fine-tune them more carefully.

Importance of Pipeline Order: The order in which different filters and corrections are applied matters greatly. For example, rotating before binarization might be better in some cases, while removing foreign objects should generally happen early in the pipeline.

Binarization Challenges: Binarization is a crucial step but is prone to creating holes or distorting the barcode, especially with low-contrast images. Strategies to mitigate this include larger window sizes in adaptive thresholding and morphological operations (closing).

Cropping Difficulties: Most codebases do a poor job of accurately cropping the barcode region, often excluding parts of the barcode or including excessive background. A more robust method is needed, perhaps involving both edge detection and analysis of the barcode pattern itself.

Foreign Object Removal is Weak: This is a major area where most codebases fail. The vertical/horizontal profile methods are not robust enough, especially when foreign objects don't have a uniform shape or are very close to the bar thickness. The vertical averaging kernel approach is the most promising but needs significant refinement.

Frequency Domain Fixes: The frequency domain correction has been inconsistent. The high-pass filter sometimes helps, but it can also degrade the barcode. A more targeted approach is required, maybe using a band-pass filter or a method to specifically address repetitive background patterns without harming the barcode's frequency components.

Rotation Fixes: Rotation correction based on Hough lines is generally good at detecting the angle, but padding is crucial to prevent cropping. Some versions are better at this.

III. Key Areas for Improvement and Proposed Solutions

Based on this extensive analysis, here are the key areas where we need to focus our efforts and the solutions I propose:

1. Foreign Object Detection and Removal

Problem: This is the most significant weakness across all codebases. Current methods are not robust enough to handle various types of foreign objects.

Proposed Solution:

Barcode Pattern Analysis: Utilize the estimated bar thickness and spacing to create a more intelligent detection mechanism. Instead of just looking at vertical and horizontal profiles, analyze local regions in the context of the expected barcode pattern.

Vertical Averaging Kernel:

The most promising approach is using a vertical averaging kernel, as introduced in codebase 17 and refined in later versions. However, it needs to be adaptive:

Kernel Size: The kernel width should be based on the estimated min_bar_width, and the height should ideally be the height of the barcode region.

Adaptive Application: Apply the kernel only to regions identified as potentially anomalous, based on the pattern analysis.

Iterative Approach: It might be necessary to apply the kernel multiple times, especially for larger or more complex foreign objects.

2. Blur Detection and Correction

Problem: Inconsistent detection, and some correction methods create artifacts.

Proposed Solution:

Detection:

Combine Laplacian variance, edge density, and frequency analysis.

Use a lower threshold for Laplacian variance (around 70-90) combined with a check on edge density.

Analyze the ratio of high-frequency to low-frequency components in the Fourier transform (as suggested in the analysis of codebase 17). A lower ratio can indicate blur.

Correction:

Unsharp Masking: Use a mild unsharp masking as the first stage.

Conditional Sharpening: Apply a sharpening kernel only if the Laplacian variance is still below a certain threshold after unsharp masking. Be careful with the parameters to avoid creating artifacts.

Adaptive parameters: You could potentially adjust the unsharp mask strength based on the estimated blur level.

3. Contrast Enhancement

Problem: Inconsistent detection and sometimes over-aggressive correction.

Proposed Solution:

Detection:

Use a combination of percentile analysis (p5, p95) and mean intensity to classify contrast issues as "dark_contrast", "bright_contrast", or "general_contrast".

Correction:

Targeted Approach: Apply different strategies based on the detected contrast type:

dark_contrast: Aggressive brightening while preserving blacks (as suggested in codebase 21 analysis).

bright_contrast: Increase black/white separation using CLAHE and potentially a very mild gamma correction.

general_contrast: Use CLAHE with moderate parameters, potentially followed by a mild gamma correction.

4. Salt and Pepper Noise

Problem: Often over-detected, and removal methods can be too aggressive.

Proposed Solution:

Detection:

Use a higher threshold for the difference between the image and its median-filtered version (e.g., 95th percentile > 50 or even 60).

Correction:

Use iterative median filtering, starting with a small kernel (3x3) and increasing only if necessary.

5. Compression Artifacts

Problem: Inconsistent detection, sometimes removal is ineffective.

Proposed Solution:

Detection: Use the Sobel filter approach to detect blocky patterns, as described in codebase 22.

Correction: Use non-local means denoising with careful parameters (h=5-10).

6. Frequency Domain Issues

Problem: Inconsistent detection and sometimes harmful correction.

Proposed Solution:

Detection: Use the standard deviation of the magnitude spectrum (as in many codebases) with a higher threshold (e.g., > 60 or 70).

Correction:

Targeted Approach: Instead of a generic high-pass filter, try to identify and remove specific frequency components related to the background pattern, while preserving the barcode frequencies. This will require a more sophisticated analysis of the frequency spectrum.

Avoid if Possible: If other fixes are effective, it might be best to avoid frequency domain operations unless the problem is severe.

7. Rotation Correction

Problem: Errors, crashes, and sometimes incomplete correction.

Proposed Solution:

Padding: Always add padding before rotation to prevent cropping.

Hough Transform: Use the Hough Transform to detect lines and calculate the median angle.

Accurate Rotation: Use cv2.getRotationMatrix2D and cv2.warpAffine with cv2.INTER_CUBIC interpolation and cv2.BORDER_CONSTANT with a border value of 255 (white).

Post-Rotation Cropping: After rotation, find the bounding rectangle of the rotated barcode and crop tightly.

Error Handling: Add checks to ensure the rotation and cropping operations are successful and handle cases where lines are not detected.

8. Binarization

Problem: Holes and distortions, especially with low contrast or uneven lighting.

Proposed Solution:

Preprocessing: Apply contrast enhancement before binarization.

Adaptive Thresholding: Use cv2.adaptiveThreshold with cv2.ADAPTIVE_THRESH_GAUSSIAN_C and cv2.THRESH_BINARY.

Parameter Tuning: Experiment with the window size (e.g., 51) and offset (e.g., 5 or 7) to find the best balance between noise reduction and hole prevention.

Morphological Closing: Apply a morphological closing operation with a small kernel (e.g., 2x2) to close small holes without significantly distorting the bars.

9. Cropping

Problem: Inconsistent and often inaccurate cropping.

Proposed Solution:

Early Detection: Detect the barcode region early in the pipeline using the detect_barcode_region function.

Refinement after Rotation: If rotation is applied, re-detect the barcode region to get more accurate coordinates.

Final Crop: After all other processing steps, perform a final tight crop based on the detected barcode region. class BarcodePreprocessor:
    def __init__(self):
        self.steps = []

    def add_step(self, description, image):
        """Save each step for visualization"""
        self.steps.append((description, image.copy()))

    # -------------------------------------
    # UTILITY FUNCTIONS
    # -------------------------------------
    def estimate_bar_thickness(self, image):
        """Estimate barcode bar thickness using vertical runs of black pixels after binarization"""
        # Use adaptive thresholding for binarization
        temp_binary = cv2.adaptiveThreshold(
            image, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C, cv2.THRESH_BINARY, 51, 7
        )

        heights = []
        for col in range(temp_binary.shape[1]):
            column = temp_binary[:, col]
            run_length = 0
            black_runs = []
            for val in column:
                if val == 0:
                    run_length += 1
                else:
                    if run_length > 0:
                        black_runs.append(run_length)
                    run_length = 0
            if run_length > 0:
                black_runs.append(run_length)
            if black_runs:
                heights.extend(black_runs)

        if not heights:
            return 3, 9 # Default fallback if no bars are detected

        min_width = max(1, int(np.percentile(heights, 10)))  # 10th percentile for min width
        pattern_width = max(3, int(np.median(heights)))  # Median for typical pattern width

        # Sanity check: Avoid extremely large values
        min_width = min(min_width, 10)
        pattern_width = min(pattern_width, 30)

        return min_width, pattern_width

    def get_anomalous_regions(self, anomalies, min_bar_width):
        """Group contiguous anomalous regions based on min bar thickness"""
        regions = []
        if len(anomalies) > 0:
            current_region = [anomalies[0]]
            for i in range(1, len(anomalies)):
                if anomalies[i] == anomalies[i-1] + 1 and anomalies[i] - current_region[0] < min_bar_width * 2:
                    current_region.append(anomalies[i])
                else:
                    regions.append(current_region)
                    current_region = [anomalies[i]]
            regions.append(current_region)
        return regions

    def detect_barcode_region(self, image):
        """Find the actual barcode region in the image using edge detection and contour analysis"""
        # Enhance vertical edges
        sobelx = cv2.Sobel(image, cv2.CV_64F, 1, 0, ksize=3)
        gradx = cv2.convertScaleAbs(sobelx)

        # Find regions with high concentration of vertical lines
        blur = cv2.GaussianBlur(gradx, (21, 21), 0)
        thresh = cv2.threshold(blur, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)[1]

        # Find connected components
        contours, _ = cv2.findContours(thresh, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

        if not contours:
            return None

        # Filter contours by aspect ratio, size, and vertical line density
        valid_regions = []
        for contour in contours:
            x, y, w, h = cv2.boundingRect(contour)
            if w < 20 or h < 10:  # Too small (adjust thresholds as needed)
                continue

            aspect_ratio = w / float(h)
            if aspect_ratio < 1.5 or aspect_ratio > 5: # Aspect ratio should be in a range
                continue
            
            roi = gradx[y:y + h, x:x + w]
            edge_density = np.sum(roi > 50) / (w * h)

            if edge_density > 0.1:
                valid_regions.append((x, y, w, h))

        if not valid_regions:
            return None

        # Return region with highest edge density
        return max(valid_regions, key=lambda r: np.sum(gradx[r[1]:r[1] + r[3], r[0]:r[0] + r[2]]))
    
    def validate_barcode_region(self, region, image):
        """Validate that a region is likely to be a barcode region based on aspect ratio and edge density."""
        x, y, w, h = region
        roi = image[y:y + h, x:x + w]

        # Check aspect ratio
        aspect = w / h
        if not (1.5 < aspect < 5):
            return False

        # Verify vertical line pattern using edge detection
        edges = cv2.Sobel(roi, cv2.CV_64F, 1, 0, ksize=3)
        edge_density = np.mean(np.abs(edges) > 50)  # Check density of strong edges

        return edge_density > 0.1
    
    def remove_foreign_object(self, image, barcode_region):
        """Remove foreign objects using bar thickness and vertical kernel averaging"""
        x, y, w, h = barcode_region
        roi = image[y:y + h, x:x + w].copy()

        # Estimate bar thickness
        min_bar_width, pattern_width = self.estimate_bar_thickness(roi)

        # Create a vertical averaging kernel
        kernel_height = h  # Height of the kernel should match ROI height
        kernel_width = min_bar_width
        kernel = np.ones((kernel_height, kernel_width)) / kernel_height

        # Calculate vertical and horizontal profiles
        vertical_profile = np.mean(roi, axis=0)
        horizontal_profile = np.mean(roi, axis=1)

        # Calculate standard deviations
        v_std = np.std(vertical_profile)
        h_std = np.std(horizontal_profile)

        # Set thresholds for anomaly detection (adaptive)
        v_threshold = np.mean(vertical_profile) + 2.5 * v_std
        h_threshold = np.mean(horizontal_profile) + 2.5 * h_std

        # Detect anomalous regions
        v_anomalous = np.abs(vertical_profile - np.mean(vertical_profile)) > v_threshold
        h_anomalous = np.abs(horizontal_profile - np.mean(horizontal_profile)) > h_threshold

        v_anomalous_regions = self.get_anomalous_regions(np.where(v_anomalous)[0], min_bar_width)
        h_anomalous_regions = self.get_anomalous_regions(np.where(h_anomalous)[0], min_bar_width)

        cleaned = roi.copy()

        # Process vertical anomalies
        for region in v_anomalous_regions:
            for i in region:
                # Look for good columns within the vicinity
                good_cols = []
                for offset in range(-pattern_width, pattern_width + 1):
                    check_idx = i + offset
                    if 0 <= check_idx < w and not v_anomalous[check_idx]:
                        good_cols.append(roi[:, check_idx])

                if good_cols:
                    # Replace anomalous column with the average of good neighbors
                    avg_col = np.mean(good_cols, axis=0)
                    cleaned[:, i:i+1] = avg_col.reshape(-1, 1)

        # Process horizontal anomalies (similar logic as vertical)
        for region in h_anomalous_regions:
            for j in region:
                good_rows = []
                for offset in range(-pattern_width, pattern_width + 1):
                    check_idx = j + offset
                    if 0 <= check_idx < h and not h_anomalous[check_idx]:
                        good_rows.append(cleaned[check_idx, :])

                if good_rows:
                    avg_row = np.mean(good_rows, axis=0)
                    cleaned[j:j+1, :] = avg_row.reshape(1, -1)

        # Apply the vertical kernel for smoothing
        smoothed = cv2.filter2D(cleaned, -1, kernel)

        result = image.copy()
        result[y:y + h, x:x + w] = smoothed
        return result

    def detect_image_problems(self, image):
        """Detect image problems with refined strategies and thresholds"""
        problems = []
        gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY) if len(image.shape) > 2 else image.copy()

        barcode_region = self.detect_barcode_region(gray)
        if barcode_region is None:
            return problems, (0, 0, gray.shape[1], gray.shape[0])

        x, y, w, h = barcode_region
        roi = gray[y:y + h, x:x + w]

        min_bar_width, pattern_width = self.estimate_bar_thickness(roi)

        # Foreign object
        if self.detect_foreign_object(roi, min_bar_width, pattern_width):
            problems.append('foreign_object')

        # Blur
        laplacian_var = cv2.Laplacian(roi, cv2.CV_64F).var()
        edges = cv2.Canny(roi, 50, 150)
        edge_density = np.mean(edges > 0)
        if laplacian_var < 70 and edge_density < 0.1:
            problems.append('blur')

        # Low contrast
        p5, p95 = np.percentile(roi, [5, 95])
        if (p95 - p5) < 60:
            problems.append('low_contrast')

        # Salt and pepper (stricter check)
        median = cv2.medianBlur(roi, 3)
        noise_diff = np.abs(roi - median)
        if np.percentile(noise_diff, 95) > 60:
            problems.append('salt_pepper')

        # Compression artifacts
        if self.detect_compression_artifacts(roi):
            problems.append('compression_artifacts')

        # Frequency domain
        f_transform = np.fft.fft2(roi)
        f_shift = np.fft.fftshift(f_transform)
        magnitude_spectrum = 20 * np.log(np.abs(f_shift) + 1)
        if np.std(magnitude_spectrum) > 65:
            problems.append('frequency_domain')

        # Rotation
        lines = cv2.HoughLines(edges, 1, np.pi/180, threshold=min(w,h)//3)
        if lines is not None:
            angles = []
            for rho, theta in lines[:, 0]:
                angle = np.degrees(theta)
                if angle < 45:
                    angles.append(angle)
                elif angle > 135:
                    angles.append(angle - 180)
            if angles and abs(np.median(angles)) > 5:
                problems.append('rotation')

        return problems, barcode_region

    def detect_foreign_object(self, roi, min_bar_width, pattern_width):
        """Detect foreign objects using pattern analysis and a rolling window standard deviation."""
        vertical_profile = np.mean(roi, axis=0)
        horizontal_profile = np.mean(roi, axis=1)

        # Calculate rolling standard deviation with a window size relative to the pattern width
        window_size = pattern_width
        v_stds = [np.std(vertical_profile[i:i + window_size]) for i in range(len(vertical_profile) - window_size + 1)]
        h_stds = [np.std(horizontal_profile[i:i + window_size]) for i in range(len(horizontal_profile) - window_size + 1)]

        # Check for significant deviations in the rolling standard deviation
        v_std_anomalies = np.where(np.abs(v_stds - np.mean(v_stds)) > 2.5 * np.std(v_stds))[0]
        h_std_anomalies = np.where(np.abs(h_stds - np.mean(h_stds)) > 2.5 * np.std(h_stds))[0]
        
        if len(v_std_anomalies) > 0 or len(h_std_anomalies) > 0:
            return True

        return False

    def detect_blur(self, roi):
        """Detect blur using a combination of Laplacian variance, edge analysis, and frequency analysis."""
        laplacian_var = cv2.Laplacian(roi, cv2.CV_64F).var()
        edges = cv2.Canny(roi, 50, 150)
        edge_density = np.mean(edges > 0)

        # Frequency analysis
        f_transform = np.fft.fft2(roi)
        f_shift = np.fft.fftshift(f_transform)
        magnitude_spectrum = 20 * np.log(np.abs(f_shift) + 1)

        # Calculate the ratio of high-frequency to low-frequency components
        rows, cols = roi.shape
        crow, ccol = rows // 2, cols // 2
        low_freq_magnitude = np.sum(magnitude_spectrum[crow-5:crow+5, ccol-5:ccol+5])
        high_freq_magnitude = np.sum(magnitude_spectrum) - low_freq_magnitude
        freq_ratio = high_freq_magnitude / low_freq_magnitude if low_freq_magnitude != 0 else 0

        # Combine metrics (lower values indicate blur)
        blur_score = laplacian_var * edge_density * freq_ratio

        return blur_score < 7

    def detect_low_contrast(self, roi):

        p5, p95 = np.percentile(roi, [5, 95])
        contrast_range = p95 - p5
        return contrast_range < 60

    def detect_compression_artifacts(self, gray):
        """Detect compression artifacts using edge analysis and block-based standard deviation."""
        # Apply Sobel filters to detect edges
        sobelx = cv2.Sobel(gray, cv2.CV_64F, 1, 0, ksize=3)
        sobely = cv2.Sobel(gray, cv2.CV_64F, 0, 1, ksize=3)
        magnitude = np.sqrt(sobelx**2 + sobely**2)

        # Calculate standard deviation in 8x8 blocks
        block_size = 8
        blocks_shape = (magnitude.shape[0] // block_size, magnitude.shape[1] // block_size, block_size, block_size)
        blocks = np.lib.stride_tricks.as_strided(magnitude, shape=blocks_shape, strides=magnitude.strides * 2)
        block_stds = np.std(blocks, axis=(2, 3))

        # Check for high standard deviation across blocks
        return np.std(block_stds) > 5  # Adjust threshold as needed

    def detect_rotation(self, roi):
        """Detect rotation using Hough Transform"""
        edges = cv2.Canny(roi, 50, 150)
        lines = cv2.HoughLines(edges, 1, np.pi/180, threshold=50)
        if lines is not None:
            angles = []
            for rho, theta in lines[:, 0]:
                angle = np.degrees(theta)
                if angle < 45:
                    angles.append(angle)
                elif angle > 135:
                    angles.append(angle - 180)
            if angles and abs(np.median(angles)) > 5:
                return True
        return False

    def fix_rotation(self, image, barcode_region):
        """Fix rotation with proper padding"""
        x, y, w, h = barcode_region
        roi = image[y:y+h, x:x+w].copy()

        # Add padding before rotation
        pad = int(max(w, h) * 0.3)
        padded = cv2.copyMakeBorder(roi, pad, pad, pad, pad, cv2.BORDER_CONSTANT, value=255)

        edges = cv2.Canny(padded, 50, 150)
        lines = cv2.HoughLines(edges, 1, np.pi / 180, threshold=50)

        if lines is not None:
            angles = []
            for rho, theta in lines[:, 0]:
                angle = np.degrees(theta)
                if angle < 45:
                    angles.append(angle)
                elif angle > 135:
                    angles.append(angle - 180)

            if angles:
                median_angle = np.median(angles)
                rows, cols = padded.shape
                matrix = cv2.getRotationMatrix2D((cols / 2, rows / 2), median_angle, 1)

                # Calculate new dimensions post-rotation
                angle_rad = np.abs(np.radians(median_angle))
                new_w = int(cols * np.abs(np.cos(angle_rad)) + rows * np.abs(np.sin(angle_rad)))
                new_h = int(rows * np.abs(np.cos(angle_rad)) + cols * np.abs(np.sin(angle_rad)))

                # Adjust rotation matrix to keep image within bounds
                matrix[0, 2] += (new_w - cols) / 2
                matrix[1, 2] += (new_h - rows) / 2

                # Perform rotation
                rotated = cv2.warpAffine(padded, matrix, (new_w, new_h),
                                         flags=cv2.INTER_CUBIC,
                                         borderMode=cv2.BORDER_CONSTANT,
                                         borderValue=255)

                # Find actual barcode region in rotated image
                edges = cv2.Canny(rotated, 50, 150)
                coords = np.column_stack(np.where(edges > 0))
                if len(coords) > 0:
                    x_, y_, w_, h_ = cv2.boundingRect(coords)

                    # Ensure that we don't end up with negative dimensions
                    x_ = max(0, x_)
                    y_ = max(0, y_)

                    rotated_crop = rotated[y_:y_ + h_, x_:x_ + w_]
                    rotated_crop = rotated_crop[:h, :w]  # Resize while keeping dimensions positive

                    result = image.copy()
                    result[y:y+h, x:x+w] = rotated_crop
                    return result
        return image

    def remove_salt_and_pepper(self, image, barcode_region):

    def fix_blur(self, image, barcode_region):

        roi = image[y:y+h, x:x+w].copy()

        # Apply unsharp masking

    def fix_frequency_domain(self, image, barcode_region):
        """Fix frequency domain issues using a high-pass filter"""
        x, y, w, h = barcode_region
        roi = image[y:y+h, x:x+w].copy()

        f_transform = np.fft.fft2(roi)
        f_shift = np.fft.fftshift(f_transform)

        rows, cols = roi.shape
        crow, ccol = rows // 2, cols // 2

        # Create a mask for a high-pass filter
        mask = np.ones((rows, cols), np.uint8)
        r = 30  # Radius to control the cutoff frequency
        x_grid, y_grid = np.ogrid[:rows, :cols]
        mask_area = (x_grid - crow)**2 + (y_grid - ccol)**2 <= r*r
        mask[mask_area] = 0

        # Apply the mask
        f_shift = f_shift * mask
        f_ishift = np.fft.ifftshift(f_shift)
        img_back = np.fft.ifft2(f_ishift)
        img_back = np.abs(img_back)

        # Normalize the result
        cleaned = cv2.normalize(img_back, None, 0, 255, cv2.NORM_MINMAX).astype(np.uint8)

        result = image.copy()
        result[y:y + h, x:x + w] = cleaned
        return result
    
    def fix_compression_artifacts(self, image, barcode_region):
        """Fix compression artifacts using non-local means denoising"""
        x, y, w, h = barcode_region
        roi = image[y:y+h, x:x+w].copy()
        
        denoised = cv2.fastNlMeansDenoising(
            roi,
            None,

            templateWindowSize=7,
            searchWindowSize=21
        )
        
        result = image.copy()
        result[y:y+h, x:x+w] = denoised
        return result

    def binarize(self, image):
        """Binarize using adaptive thresholding"""
        # Normalize contrast
        p2, p98 = np.percentile(image, (2, 98))
        normalized = np.interp(image, (p2, p98), (0, 255)).astype(np.uint8)

        # Adaptive threshold
        binary = cv2.adaptiveThreshold(
            normalized,
            255,
            cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
            cv2.THRESH_BINARY,
            51,  # window size
            5    # constant subtracted from mean
        )

        # Light cleanup
        kernel = np.ones((2, 2), np.uint8)
        binary = cv2.morphologyEx(binary, cv2.MORPH_CLOSE, kernel)

        return binary

    def final_cleanup(self, binary):
        """Final cleanup using vertical averaging"""
        min_bar_width = self.estimate_bar_thickness(binary)[0]
        min_bar_width = max(1, min(min_bar_width, 10))  # Ensure reasonable value

        # Create vertical averaging kernel
        kernel = np.ones((binary.shape[0], min_bar_width)) / binary.shape[0]

        # Apply kernel
        cleaned = np.zeros_like(binary)
        for i in range(0, binary.shape[1] - min_bar_width + 1):
            region = binary[:, i:i+min_bar_width]
            vertical_avg = np.mean(region, axis=0)
            cleaned[:, i:i+min_bar_width] = (vertical_avg > 127).astype(np.uint8) * 255

        return cleaned
