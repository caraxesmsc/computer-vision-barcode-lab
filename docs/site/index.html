01 / THE PROBLEM

A barcode is simple.
Reading one isn’t always.

The data lives in the width of the bars and the spaces between them. Change the image, and that delicate rhythm can disappear.

Our coursework began with eleven images: some clean, others blurred, rotated, washed out, noisy, or partially obstructed. The challenge was to recover a usable signal before trying to read it.

01Light & contrast

Details disappear into dark or washed-out backgrounds.

02Noise & blur

Pixel noise and compression obscure the edges we need.

03Rotation

Bars must be aligned before their widths can be measured.

04Obstruction

An object over the bars can erase information entirely.

03 / THE APPROACH

From pixels
to a pattern.

There was no single magic filter. The recovered pipeline combines small, purpose-built steps to make the barcode easier to interpret.

01 / PREPARE

Simplify the image

Convert to grayscale, look for periodic noise in the frequency domain, and apply adaptive thresholding when the heuristic detects it.

GRAYSCALE + FFT
02 / ALIGN

Find the direction

Use edges and contours to estimate the barcode’s orientation, then rotate the image toward a horizontal reading position.

EDGES + CONTOURS
03 / CLEAN

Recover the signal

Filter noise, threshold, stretch contrast, extract the region and apply morphology to simplify the barcode pattern.

FILTER + CROP
04 / READ

Measure the rhythm

Reduce columns to a profile, estimate narrow and wide runs, and match their patterns to the Code 11 dictionary.

PROFILE + DECODE

When the first pass misses: the recovered benchmark tries alternative crops and foreign-object removal, using the expected answer to decide whether to stop.

04 / THE RESULT

Progress,
with perspective.

The recovered variant matched 10 of the 11 expected payloads in our local run.

The obstruction case returned an empty payload. It is a useful reminder that preprocessing cannot always recover information hidden by an object.

A note on the number

The retry logic is given each expected answer. This is a known-answer benchmark, not a measure of performance on unknown barcodes. It does not validate Code 11 checksums.
