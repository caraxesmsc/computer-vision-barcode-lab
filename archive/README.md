# Historical material

These files preserve earlier experiments and recovered material for reference. They are not the maintained benchmark entry point and may assume their original working-directory paths.

- `experiments/` contains earlier scripts, numbered working folders, generated debug images, and logs from the original repository.
- `notes/` contains historical test notes and collected code excerpts.
- `outputs/` contains earlier generated visualizations.
- `recovered/` contains the second recovered version 89 source snapshot and the team's presentation script. Neither is used by the current benchmark.

For the runnable pipeline, test images, and usage instructions, see the [main README](../README.md) and [technical documentation](../docs/PROJECT.md).
